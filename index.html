Inicializando…

Precisa de um servidor estatico. ES Modules nao carregam via file://. Se esta tela nao sair daqui, rode na raiz do projeto: npm start e abra http://localhost:8080/.

WebGL2 nao suportado

Este navegador ou dispositivo nao expoe um contexto WebGL2. 


    

      O que tentar:
      atualize o navegador (Chrome/Edge 56+, Firefox 51+, Safari 15+),
      habilite a aceleracao por hardware nas configuracoes,
      atualize o driver de video, ou abra a pagina em outra maquina.
      Lembre tambem de servir os arquivos com npm start.
